# ISIT 300 resume

**Style C.** These files are a skeleton. They will not look finished until you add your content. Nothing here is a sample resume you can submit.

## How to start

On GitHub, choose **Use this template** (or fork), then clone **your** copy.

Open `resume.html` in a browser. You should see headings for the sections and no real resume content yet.

## Your work by week

- Week 1: Replace every `TODO(student)` in `resume.html` with your information. Use `h1`–`h3`, `p`, `ul`/`ol`, `strong`, and `em`. Do not add CSS yet.
- Week 5: Fill `styles.css` and confirm the `<link>` in `resume.html`. Layout, spacing, and a simple two-column area are your work.
- Week 6: Fill `script.js`. The page should do something useful on click (show/hide or highlight). Do not leave the TODO alert in place.
- Week 7: `pokemon.html` is an empty fetch lab. Request one Pokémon from PokéAPI and show a loading state, a result, and an error state.

Keep this repo for the resume track. Later application work lives in `isit300-dev`.
